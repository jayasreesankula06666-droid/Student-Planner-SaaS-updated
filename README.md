# Student Planner SaaS

A beginner-friendly student project that helps students organize assignments, study sessions, exams, and deadlines.

## Features
- Add, complete, filter, and delete tasks
- Add and remove study schedule items
- Add and remove exam dates and deadlines
- Dashboard counts and task-completion progress
- Responsive layout for desktop and mobile
- Saves demo data in the browser using `localStorage`

## Technologies
- HTML
- CSS
- JavaScript

## Run locally
1. Download and extract the ZIP file.
2. Open `index.html` in a web browser.

No build tools or installation are required.

## Upload to GitHub
1. Create a repository named `Student-Planner-SaaS`.
2. Open the repository and select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` (or upload the extracted folder's files).
4. Commit the changes.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for deployment. GitHub will show the website URL in the Pages section.

## Important note about the SaaS model
This is a front-end prototype for a student project, not a complete multi-user SaaS product. Data is stored only in the current browser. A real SaaS version would need user authentication, a server/backend, a cloud database, privacy protections, and subscription/payment integration if paid plans are offered.
